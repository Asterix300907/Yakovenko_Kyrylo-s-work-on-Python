## Опис
Реалізація п'яти завдань з теми ітераторів та генераторів у Python: власні класи-ітератори з протоколом ітерації, ітерабельні контейнери з незалежними ітераторами, функції-генератори з оператором yield, конвеєрна обробка даних (pipeline) та порівняння ефективності list comprehension і generator expression.

## Зміст завдань
1. **Власний ітератор CyclicRange** — клас-ітератор, що циклічно генерує числа від start до stop-1 з кроком step, повторюючи послідовність repeats разів. Реалізовано протокол ітерації      через методи __iter__() та __next__(), підтримка list(), sum(), for.
2. **Ітерабельний контейнер StudentGroup** — клас, що зберігає список студентів (namedtuple) і дозволяє багаторазовий незалежний обхід. Окремий клас StudentGroupIterator повертається при кожному виклику __iter__(). Додано метод top_students(n) для отримання ітератора по найкращих студентах.
3. **Генератори числових послідовностей** — набір функцій-генераторів: нескінченна арифметична прогресія, геометрична прогресія з обмеженням, числа Фібоначчі (скінченні та нескінченні), послідовність Коллатца (3n+1), рекурсивне розгортання вкладених списків через yield from.
4. **Конвеєр генераторів для обробки даних** — pipeline з 5 етапів (джерело → фільтр порожніх → парсинг → фільтр за оцінкою → форматування) для обробки текстових записів про оцінки студентів. Дані обробляються потоково без проміжних списків, з обробкою некоректних записів.
5. **Порівняння підходів до обробки даних** — демонстрація різниці між list comprehension та generator expression за використанням пам'яті (sys.getsizeof) та продуктивністю (timeit). Практичні приклади з sum(), max(), any(), all(), ",".join().

## Як запустити
1. На комп'ютері має бути встановлено Python 3.x.
2. Зовнішні бібліотеки не потрібні (використовується лише стандартна бібліотека itertools,collections, typing, sys, timeit).
3. Запустіть кожен файл окремо:
python Task1_1.py   # Завдання 1.1 — CyclicRange
python Task1_2.py   # Завдання 1.2 — StudentGroup
python Task2_1.py   # Завдання 2.1 — Генератори послідовностей
python Task2_2.py   # Завдання 2.2 — Конвеєр генераторів
python Task3_1.py   # Завдання 3.1 — Порівняння підходів
Або через Visual Studio: відкрийте проект Practice_Work_2, виберіть потрібний .py файл як стартовий (права кнопка → Set as Startup File) і натисніть F5.
