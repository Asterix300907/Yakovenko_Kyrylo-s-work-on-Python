## Опис
Реалізація чотирьох завдань з теми обробки виключень, модульної організації коду та документації в Python: базові конструкції try/except/else/finally, контекстні менеджери, ієрархія доменних виключень з ланцюжками та повторним піднесенням, пакетна структура з підпакетами та повне документування публічного API у стилі Google.

## Зміст завдань
1. **Обробка виключень** (Task1.py): три сценарії — базовий try/except для читання JSON-файлів, повний try/except/else/finally для математичних операцій, перехоплення кількох типів виключень одним блоком. Власний контекстний менеджер LogFile, що замінює явний try/finally.
2. **Ієрархія доменних виключень** (Task2.py): базовий клас LibraryError та три підкласи (ValidationError, ResourceNotFoundError, BusinessLogicError) з додатковими атрибутами та перевизначеним __str__. Демонстрація ланцюжка виключень через raise ... from ... та повторного піднесення через raise без аргументів.
3. **Організація коду в пакет** (Task3.py + library_app/): пакет library_app з двома підпакетами (core та utils) та чотирма модулями. Три форми імпорту (абсолютний, вибірковий, відносний), __all__ у __init__.py, блок if __name__ == "__main__".
4. **Документування та інтроспекція** (Task4.py): docstrings у стилі Google для всіх публічних класів і методів, анотації типів (typing.Optional, typing.Dict, typing.List), інтроспекція через help(), __doc__, __name__, __annotations__.


## Як запустити
1. На комп'ютері має бути встановлено Python 3.x.
2. Зовнішні бібліотеки не потрібні — використовується лише стандартна бібліотека (json, os, typing, abc).
3. Кожне завдання запускається окремо:
python Task1.py          # Завдання 1 — обробка виключень
python Task2.py          # Завдання 2 — ієрархія виключень
python Task3.py          # Завдання 3 — пакетна структура
