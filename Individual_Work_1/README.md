# Практична робота №1: Базові оператори, умовні конструкції та цикли в Python
**Виконав:** Яковенко Кирило, група БІКСб1-25-40д
**Дисципліна:** Програмування

## Опис
Розробка консольної програми на Python, що демонструє застосування базових операторів, умовних конструкцій (if/elif/else), циклів (for, while), різних структур даних (списки, кортежі, словники), а також реалізацію власних ітераторів і функцій-генераторів для обходу колекцій та лінивих обчислень. Програма має модульну структуру з інтерактивним меню та покриває всі критерії оцінювання самостійної роботи.

## Зміст завдань
1. **Математичні обчислення** — факторіал числа. Реалізовано два підходи: ітеративний (через цикл for) та рекурсивний. Демонструє еквівалентність підходів та роботу з цілими числами довільної точності.
2. **Робота з геометричними фігурами** Словник SHAPES, де ключ — назва фігури, а значення — кортеж із описом параметрів і лямбда-функцією обчислення площі. Підтримуються: коло, квадрат, прямокутник, трикутник, трапеція. Демонструє комбіноване використання словників, кортежів і функцій вищого порядку.
3. **Структури даних**: список, кортеж, словник. Демонстрація мутабельності списку (додавання, сортування), незмінюваності кортежу (обчислення статистик), та роботи зі словником (створення через zip, фільтрація через dict comprehension).
4. **Власний ітератор PrimeIterator** Клас-ітератор, що генерує прості числа до заданої межі. Реалізовано протокол ітерації через __iter__() та __next__(), алгоритм перевірки простоти з оптимізацією (перевірка до √n з кроком 6).
5. **Функції-генератори** Генератор чисел Фібоначчі (підтримує скінченний і нескінченний режими через Optional[int]), генератор послідовності Коллатца (3n+1), generator expression для обчислення суми квадратів парних чисел. Демонструє ліниві обчислення — пошук першого числа Фібоначчі > 1000 зупиняється одразу після знаходження.
6. **Аналіз числа (умовні конструкції та цикли)** Інтерактивний модуль: визначення знаку та парності числа, обчислення суми цифр, пошук дільників через list comprehension, перевірка на простоту.
7. **Головне меню** Словник MENU із парами "код → (опис, функція)", цикл while True з обробкою некоректного вводу та командою виходу.
## Як запустити
1. На комп'ютері має бути встановлено Python 3.9+.
2. Зовнішні бібліотеки не потрібні — використано лише стандартну бібліотеку (math, typing).
3. Запустіть основний файл командою: `python Individual_Work_1.py`.
Після запуску з'явиться інтерактивне меню, де можна обрати потрібний модуль (1–6) або вийти з програми (0).
