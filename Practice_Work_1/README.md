# Практична робота №1: Базові оператори, умовні конструкції та цикли в Python
**Виконав:** Яковенко Кирило, група БІКСб1-25-40д
**Дисципліна:** Програмування

## Опис
Розробка програмних модулів з використанням базових операторів, стандартних функцій, умовних конструкцій if/elif/else та циклів for/while для розв'язання обчислювальних задач.

## Зміст завдань
1. **Обчислення математичних виразів:** сума квадратів, середнє арифметичне, дискримінант, гіпотенуза, перевірка нерівності трикутника.
2. **Стандартні функції та перетворення типів:** конвертор типів (int, float, bool), демонстрація type(), isinstance(), id(), len(), range(), f-рядки з форматуванням.
3. **Класифікація оцінок за шкалою ЄКТС:** if/elif/else, перевірка діапазону 0–100, обробка некоректного введення.
4. **Визначення типу трикутника та обчислення площі:** вкладені умови, нерівність трикутника, теорема Піфагора з похибкою, формула Герона.
5. **Цикл for:** обчислення факторіала, гармонічного ряду, таблиця множення n×n з вирівнюванням.
6. **Цикл while з управлінням потоком:** інтерактивний калькулятор з підтримкою +, -, *, /, //, %, **, командами quit та history, обробкою ділення на нуль.

## Як запустити
1. На комп'ютері має бути встановлено Python 3.x.
2. Зовнішні бібліотеки не потрібні (використовується лише стандартний модуль `math`).
3. Запустіть основний файл командою: `python Practice_Work_1.py`.
