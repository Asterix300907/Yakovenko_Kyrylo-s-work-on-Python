## Опис
Реалізація та порівняння основних структур даних Python (списки, кортежі, словники, множини) та експериментальний аналіз їх алгоритмічної складності.

## Зміст завдань
1. **Списки:** індексація, зрізи, мутації in-place, аналіз створення копій об'єктів.
2. **Кортежі:** розпакування даних, агрегація, демонстрація іммутабельності та поведінки вкладених мутабельних об'єктів.
3. **Словники:** підрахунок частот слів, нормалізація тексту, безпечний доступ, сортування та фільтрація (dict comprehension).
4. **Множини:** операції об'єднання, перетину, симетричної різниці, перевірка підмножини.
5. **Алгоритмічна складність:** порівняння швидкодії пошуку та видалення дублікатів у list, set, dict на вибірках розміром 1 000, 10 000 та 50 000 елементів.

## Як запустити
1. На комп'ютері має бути встановлено Python 3.x.
2. Зовнішні бібліотеки не потрібні (використовується лише стандартний модуль `time`).
3. Запустіть основний файл командою: `python Lab_Work_1.py`.
