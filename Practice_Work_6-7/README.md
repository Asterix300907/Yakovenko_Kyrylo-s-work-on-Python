## Опис

Реалізація семи завдань з теми веб-розробки на Flask: маршрутизація та обробка запитів (GET, POST), контролери з валідацією JSON, робота з cookies та sessions, CRUD-операції через HTML-форми, повний REST API з серіалізацією, фільтрацією та централізованою обробкою помилок.

## Зміст завдань

### Частина 1. Маршрутизація та обробка запитів

**1. Маршрутизація для GET та POST запитів (Task1_1.py):** Реалізовано 7 маршрутів Flask зі статичними та динамічними URL-параметрами (`<int:>`, `<string:>`). Обробка GET-параметрів через `request.args` (пагінація, пошук), POST-даних через `request.form` (створення публікацій). Використано `redirect()` після POST (патерн Post/Redirect/Get), `abort(404)` для неіснуючих ресурсів, `url_for()` для генерації URL.

**2. Контролери/views для обробки запитів (Task1_2.py):** Реалізовано REST API для колекції елементів (items) з повним набором HTTP-методів (GET, POST, PUT, DELETE). Створено декоратор `validate_json` для централізованої валідації JSON-даних. Реалізовано фільтрацію за категорією та діапазоном цін, сортування за name/price. Повертаються коректні HTTP статус-коди (200, 201, 204, 400, 404).

**3. Cookies та sessions (Task1_3.py):** Імплементовано роботу з cookies для збереження уподобань користувача (тема, мова) з параметрами `max_age`, `httponly`, `samesite`. Реалізовано кошик покупок через sessions з підрахунком загальної суми. Реалізовано імітацію авторизації з перевіркою сесії та захистом маршруту `/profile`. Продемонстровано різницю між клієнтськими cookies та серверними sessions.

### Частина 2. CRUD операції

**4. Create та Read через веб-інтерфейс (Task2_1.py):** Реалізовано HTML-форму для створення публікацій з валідацією непорожніх полів. Реалізовано відображення списку з пагінацією (по 5 постів на сторінку) та детальне відображення запису. Використано `flash()` для повідомлень про успіх/помилку з категоріями (error — червоний, стандартна — зелений).

**5. Update та Delete з валідацією (Task2_2.py):** Реалізовано форму редагування з попередньо заповненими полями та валідацією. Реалізовано сторінку підтвердження видалення з двома кнопками ("Так, видалити" / "Скасувати"). Використано спільний шаблон `FORM_TEMPLATE` для створення та редагування (принцип DRY). Оброблено `abort(404)` для неіснуючих записів.

### Частина 3. REST API

**6. REST API ендпоінти (Task3_1.py):** Спроектовано та реалізовано повний REST API для ресурсу "Студент" з ендпоінтами GET (список), GET (деталі), POST, PUT, PATCH, DELETE. Реалізовано фільтрацію за кількома параметрами (group, min_gpa), пагінацію (page, per_page), сортування (sort_by, order). Реалізовано ендпоінт статистики `/api/students/stats` з агрегацією даних (total, avg_gpa, groups, top_students). Повертаються коректні HTTP статус-коди (200, 201, 204, 400, 404, 422).

**7. Серіалізація, фільтрація та обробка помилок (Task3_2.py):** Створено клас `StudentSerializer` з методами `serialize`, `deserialize`, `serialize_list` та підтримкою обчислювального поля `grade` (відмінно/добре/задовільно/незадовільно). Реалізовано вибір полів відповіді через `?fields=name,gpa` та текстовий пошук через `?search=query`. Створено декоратор `require_api_key` для авторизації через заголовок `X-API-Key`. Створено клас `APIError` для централізованої обробки помилок. Реалізовано middleware `@app.before_request` / `@app.after_request` для логування запитів та додавання CORS-заголовків (`X-Request-Time`, `Access-Control-Allow-Origin`).

## Як запустити

На комп'ютері має бути встановлено **Python 3.10+**.

Зовнішні бібліотеки: `flask` (встановлюється через `pip install flask`).

Кожне завдання запускається окремо:

```bash
python Task1_1.py   # Частина 1, Завдання 1.1 — маршрутизація (порт 5000)
python Task1_2.py   # Частина 1, Завдання 1.2 — контролери/views (порт 5000)
python Task1_3.py   # Частина 1, Завдання 1.3 — cookies та sessions (порт 5000)
python Task2_1.py   # Частина 2, Завдання 2.1 — Create та Read (порт 5000)
python Task2_2.py   # Частина 2, Завдання 2.2 — Update та Delete (порт 5000)
python Task3_1.py   # Частина 3, Завдання 3.1 — REST API ендпоінти (порт 5000)
python Task3_2.py   # Частина 3, Завдання 3.2 — серіалізація та обробка помилок (порт 5000)

Тестування API через curl
# GET з фільтрацією та пагінацією
curl "http://127.0.0.1:5000/api/students?page=1&per_page=2&sort=gpa&order=desc"

# POST з авторизацією
curl -X POST http://127.0.0.1:5000/api/v2/students \
  -H "Content-Type: application/json" \
  -H "X-API-Key: secret-api-key-123" \
  -d '{"name": "Тест", "group": "КІ-24", "email": "test@kpi.ua", "gpa": 75}'

# PATCH — часткове оновлення
curl -X PATCH http://127.0.0.1:5000/api/v2/students/1 \
  -H "Content-Type: application/json" \
  -d '{"gpa": 90.0}'

# DELETE
curl -X DELETE http://127.0.0.1:5000/api/students/1 -v

# Перевірка заголовків (CORS, X-Request-Time)
curl -v http://127.0.0.1:5000/api/v2/students/1

Робота з cookies та sessions (curl)
# Авторизація (зберегти cookies у файл)
curl -c cookies.txt -X POST http://127.0.0.1:5000/login \
  -H "Content-Type: application/json" \
  -d '{"username": "Кирило"}'

# Перегляд профілю (використати cookies)
curl -b cookies.txt http://127.0.0.1:5000/profile

# Додавання товару до кошика (зберегти та використати cookies)
curl -b cookies.txt -c cookies.txt -X POST http://127.0.0.1:5000/cart/add/1

# Перегляд кошика
curl -b cookies.txt http://127.0.0.1:5000/cart
