## Опис
Реалізація п'яти взаємодоповнюваних завдань з ООП: класові ієрархії з наслідуванням та поліморфізмом, інкапсуляція з контролем доступу, магічні методи та перевантаження операторів, абстрактні класи з композицією, паттерн проектування Strategy.

## Зміст завдань
1. **Класова ієрархія:** транспортні засоби (Vehicle → Car, Truck, Motorcycle), поліморфний обхід, isinstance/issubclass.
2. **Інкапсуляція:** датчик температури з приватним атрибутом (__), захищеним атрибутом (_), @property з валідацією, обчислюваною властивістю та name mangling.
3. **Магічні методи:** клас Vector2D з перевантаженням операторів (+, *, ==, abs) та методами __str__/__repr__.
4. **Абстрактні класи та композиція:** система обробки замовлень з абстрактним PaymentProcessor (abc.ABC) та делегуванням через композицію.
5. **Паттерн Strategy:** динамічне форматування звітів (Plain Text, HTML, JSON) з демонстрацією розширюваності без зміни існуючого коду.

## Як запустити
1. На комп'ютері має бути встановлено Python 3.x.
2. Зовнішні бібліотеки не потрібні (використовується лише стандартна бібліотека `abc` та `math`).
3. Запустіть основний файл командою: `python Lab_Work_2.py`.
