## Опис
Реалізація шести завдань з теми розширених можливостей ООП у Python: метакласи та динамічне створення класів, дескриптори атрибутів, декоратори функцій і класів, а також застосування паттернів проектування (Singleton, Factory Method, Observer, Strategy, MVC).

## Зміст завдань
1. **Метакласи та динамічне створення класів (Task1_1.py):** Система плагінів з автоматичною реєстрацією та валідацією через метаклас `PluginMeta`. Демонстрація створення класу на льоту через `type()`.
2. **Дескриптори та `__init_subclass__` (Task1_2.py):** Система конфігурації з автоматичною реєстрацією секцій. Типізований дескриптор `ValidatedField` для валідації типу та діапазону значень атрибутів.
3. **Декоратори функцій (Task2_1.py):** Декоратори з параметрами: `cache` (обмеження розміру кешу), `rate_limit` (обмеження частоти викликів) та `log` (логування з вимірюванням часу).
4. **Декоратори класів (Task2_2.py):** Декоратори `auto_repr` (автоматичний `__repr__`), `frozen` (заборона зміни атрибутів після ініціалізації) та `log_methods` (логування публічних методів).
5. **Singleton та Factory Method (Task3_1.py):** Система логування з єдиним екземпляром логера (через метаклас) та фабрикою форматерів (Plain, JSON, Color) з підтримкою реєстрації нових типів.
6. **Observer, Strategy та MVC (Task3_2.py):** Система управління завданнями (To-Do List) з подіями (`EventEmitter`), стратегіями сортування та розділенням на Model, View, Controller.
